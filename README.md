# Hoppydf 26.10 - converte le fatture elettroniche italiane in PDF

Converti le fatture elettroniche da .p7m e .xml a .pdf in un solo click. Gratis!

<img width="356.66" height="350" alt="icon" src="https://github.com/user-attachments/assets/50819d75-b3cb-4d5f-9da3-17ff374f735b" />


Avvia Hoppydf e seleziona la cartella che contiene le tue fatture elettroniche (in formato XML o P7M). Il programma analizza la struttura dati di ogni fattura e compila un documento PDF unico formattato in modo pulito e professionale.

Se usi il codice sorgente, assicurati di avere installato le dipendenze necessarie (```requirements.txt```).
